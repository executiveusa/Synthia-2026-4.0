# Structure log — the studio's memory of what it already made

Purpose: stop the studio from shipping the same structure to every client
(see `_factory/knowledge/design-creativity-bench.md`, principle 2).

Each delivered project adds one row at `08_learn`. **No client content**: no names, copy,
images or brand colours. Only the structural answers, so this file can live in the repo.

At `03_direction`, the reviewer reads the last 10 rows for the same offer. A new direction that
gives the same answer as a past project on **every** structural question is a repeat: rework it
or justify it in writing (e.g. the client asked for that pattern).

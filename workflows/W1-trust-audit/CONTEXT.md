# W1 — Website Trust & Slop Audit

**Sells as:** a paid audit (Fiverr/Upwork) and, in short form, the free opener for direct outreach.
**Mode:** `audit_only`. Never changes the client's site.
**Deliverable:** an owner-readable report with ranked, evidenced findings and a fix quote.
**Rubric profile:** `audit`.

Stages: `00_lock → 01_inspect → 02_audit → 05_gauntlet → 06_approval → 07_deliver → 08_learn`
(03 and 04 are skipped: an audit has no direction or build. Numbers match the spine.)

Run one stage at a time. Read only that stage's `CONTEXT.md` and the inputs it names.
Status is whatever exists in each stage's `output/`.

Upsell path: P0 findings → W5 mobile polish or W2 landing page rebuild.

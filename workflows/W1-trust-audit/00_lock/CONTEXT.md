# 00_lock — agree what is audited and why

One job: pin down the site, the owner's goal and the one primary action the site must drive.

## Inputs
- Client order or prospect URL
- `skills/grill-me/SKILL.md` (interview method)
- `_factory/canon/SPINE.md` §00_lock (lock fields)

Do NOT load: workflow stages after this one; other workflows.

## Process
1. Run grill-me. For a cold prospect (outreach), infer the lock from the live site and mark every field INFERRED.
2. Record site type (service, portfolio, nonprofit, ecommerce, SaaS, editorial, marketplace).
3. Record mode `audit_only`. This workflow never changes the client's site.

## Outputs
- LOCK.md → output/

## Human check
Confirm the primary action is right. A wrong primary action makes every finding wrong.

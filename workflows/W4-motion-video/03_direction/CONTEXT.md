# 03_direction — script and three looks

One job: write the script and propose three distinct looks.

## Inputs
- ../00_lock/output/LOCK.md
- ../01_inspect/output/ASSETS.md
- ../02_research/output/LEDGER.md

Do NOT load: build tooling.

## Process
1. Script beat by beat with seconds: hook (0–3s), problem or tension, product in action, proof, action.
2. Design-space table for this video (story logic, hook device, camera grammar, where the product enters, end-card structure) with the defensible answers to each.
3. Three looks: restrained, expressive, experimental. Each takes a different set of answers from the table, not just a different type, colour or music. Check them against the last 10 video rows of `_factory/learn/STRUCTURE_LOG.md`.
4. Run The Extractor on the script.

## Outputs
- SCRIPT.md → output/
- DESIGN_SPACE.md (structural questions, answers, which look takes which) → output/
- frames/ (3 still frames per look) → output/

## Human check
Client or owner picks one look. Never blend the three.

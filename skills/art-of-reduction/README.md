# The Art of Reduction

A portable editing skill for copy, design, interfaces, documents, brands, workflows, and code.

Read SKILL.md first. The source map explains which upstream skill to consult for each medium. The Ubuntu example demonstrates the audit-before-edit contract.

Install by copying this folder into the target agent's skills directory, or add the SKILL.md through that agent's supported skill-management interface. This package does not install hooks or alter an existing project. Do not replace a project's HEART_AND-SOUL.md automatically.

Invoke: “Use the art of reduction. Audit this first, show what stays and what goes, then propose the smallest useful version.”

Run the structural check: python tests/check_skill.py

# Gig draft — W4 Code-Rendered Motion Video

**Title:** I will make a launch video for your product, rendered from code in every format you need

**Description:**

A short video that shows what your product does and ends on one clear action.

How it differs from a template video: it is built in code (Remotion), with your
real fonts, colors and product screens. That means:

- every format you order (16:9, 9:16, 1:1) is laid out for that screen, not cropped;
- text stays sharp at any size;
- if you order the source, you can change a headline or a price and render it again yourself.

**Process:** one-sentence message agreed first → script and three looks → you pick
one → draft → your changes → final files.

**What I need from you:** product link or screen recording, logo, brand colors and fonts,
and the one thing viewers should do at the end.

**Packages:** length, formats, revisions, source files and price to be set from `sales/pricing-tests.md`.

**Gallery:** from W4 `08_learn`, with client permission. None yet.

**FAQ**
- *Can you add claims like "10x faster"?* Only if you can show where the number comes from.
- *Music?* Licensed tracks only; the license is included in the delivery.
